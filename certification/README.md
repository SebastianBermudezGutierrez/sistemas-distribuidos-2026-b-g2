## Skills summary
In this course I learned to design cloud solutions around reliability, performance and operability instead of just deploying servers. I practiced centralized logging with Log Tank Service and metrics monitoring with Cloud Eye so a solution can be observed and operated. I designed network connectivity using EIP, NAT Gateway, VPC Peering, DNS and Enterprise Router to control how traffic enters, leaves and moves between networks. I applied horizontal scaling to build a distributed, highly elastic service system, deploying Discuz! as an example. I also designed the database tier of a solution for high reliability using cloud database services. These techniques help me reason about trade-offs in the distributed system of our Salud Activa project, such as isolating services, scaling them independently and monitoring them in production.
